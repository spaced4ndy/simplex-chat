# Plan: a received Markdown file in the app's file viewer

Tapping a received `.md` file opens it in the app's viewer, in its "Formatted" view: headings, bold text, lists, links and tables drawn as such. A button in the viewer's top bar, `<>` (in the tree an image such as "Embed Code" or "chevron.left.forwardslash.chevron.right"), switches to the "Text" view, the file's text as written, and back. The viewer remembers the view last chosen, so always return it to the Formatted view before closing it. Close the viewer by swiping it down.

A peer, alice, sends the files. In a correctly formatted view none of the Markdown markers show as text: no `#` or `##` before headings, no `**` around bold words, no `[text](address)` for links, no `- ` before list items. Raw HTML tags in a file (`<img …>`, `<br>`, `<a …>`) are not drawn as HTML here: the app shows them as text, as written. The reviewer compares these screenshots between runs before and after a change: take every shot the plan names, with the viewer fully open and nothing covering it. For each `ui find` the plan names, quote its output.
